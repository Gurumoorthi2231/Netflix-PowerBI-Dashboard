# Netflix-PowerBI-Dashboard
📊 Interactive Netflix Dashboard built using Power BI. Analyzes 8,800+ Netflix titles with insights on ratings, genres, countries, directors, and release trends using Power Query and DAX.
# Netflix Power BI Dashboard

## Project Overview
This Power BI dashboard analyzes Netflix Movies and TV Shows data.

## Key Insights
- Total Shows: 8.8K
- Ratings Analysis
- Genre Analysis
- Country-wise Analysis
- Movies vs TV Shows Comparison
- Release Year Trends

## Tools Used
- Power BI
- Power Query
- DAX
- Excel/CSV
